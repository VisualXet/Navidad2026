## 📱 Instalación en iPhone, iPad, Android y Windows
- **iPhone / iPad (Safari):** Abre la URL, pulsa el botón **Compartir** (icono cuadrado con flecha hacia arriba) y selecciona **"Añadir a pantalla de inicio"**.
- **Android (Chrome):** Abre la URL y pulsa **"Instalar aplicación"** o **"Añadir a pantalla de inicio"**.
- **Windows (Edge / Chrome):** Pulsa el icono de instalación en la barra de direcciones para anclarla como aplicación de escritorio.
